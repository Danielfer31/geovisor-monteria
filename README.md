# Geovisor de Montería

Versión pública estática (v1.0) del Geovisor de Montería, con disposición adaptable para móvil.

[Ver el geovisor](https://danielfer31.github.io/geovisor-monteria/)

`index.html` es una instantánea exportada con las capas incorporadas; no requiere un servidor de aplicación. Los mapas base se cargan al abrir la página desde OpenStreetMap y Esri, por lo que requiere conexión a internet.

Las fuentes, atribuciones y límites de interpretación están indicados dentro del visor. Atribución de OpenStreetMap: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), licencia ODbL.
